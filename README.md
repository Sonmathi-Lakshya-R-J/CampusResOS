# CampusResOS



University timetables involve shared resources such as classrooms, faculty, sections, and 
time slots, making conflicts and resource-allocation problems difficult to identify and 
manage manually. A timetable may assign the same classroom to multiple sections, 
exceed classroom capacity for combined classes, or require faculty to shift classes when 
suitable rooms are unavailable. 
Our project aims to provide a centralized web-based system that validates timetables, 
analyzes resource conflicts, supports controlled classroom booking and schedule changes, 
and demonstrates how Operating Systems and DBMS concepts work together in a 
practical academic environment.
